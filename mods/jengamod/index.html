What it is.

We watched a systemzee clip of in-game Jenga and went looking for the download. Nobody had shipped it. So we built it. Blocks stack into a proper tower, behave like they have weight, and tip when you yank the wrong one.

How it plays.

Set up a tower, take turns pulling blocks, and try not to be the one who brings it down. It plays solo, but it's a lot funnier with a few people on a server crowded around one increasingly wobbly stack.

Source & issues.

The code is public. Found a bug or want a tweak? The Jenga repos live on GitHub under @ToasterStudiosMods — Jenga-Mod for the code, plus Jenga-permissions and Jenga-Issues. Open an issue, we read them.
