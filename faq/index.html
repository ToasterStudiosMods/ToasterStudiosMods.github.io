Questions, answered.

The stuff people ask most about our mods - installing them, what they need to run, the rules on sharing, and how to get help. Tap a question to expand it.

What is Toaster Studios?

Toaster Studios is a one-person Minecraft mod studio (plus a cat named Toaster) based in New Jersey. We make small, slightly cursed Fabric mods - physics jokes, oddly specific mechanics, and recreations of mods people have shown off in videos but never actually released.

What mods do you make?

Two are live right now:

  • Jenga Mod - real physics Jenga built on the Sable engine.
  • Off da grid blocks - place fully working blocks at any angle, off the grid.

You can see everything on the Mods page, and more are in the oven.

Are the mods free?

Yes. Every mod is free to download from our Modrinth page. Please only download from official sources so you get a clean, up-to-date file.

How do I install a mod?

Our mods run on the Fabric mod loader. The short version:

  • Install Fabric Loader for Minecraft 1.21.1.
  • Put Fabric API in your mods folder.
  • Add the mod's .jar (and any dependencies it lists) to the same mods folder.
  • Launch the game with the Fabric profile.

A launcher like the Modrinth app or Prism Launcher handles most of this for you.

Do the mods need other mods to run?

All of them need Fabric API. Some need more - for example, Jenga Mod requires the Sable physics engine, since that's what makes the pieces actually move. Each mod's page and Modrinth listing spells out exactly what it needs.

Do they work in multiplayer / on a server?

Generally yes, but they need to be installed on both the client and the server, on the same Minecraft version. These mods change how the game behaves, so a vanilla client can't join a server running them and expect it to work. Check each mod's page for its specifics.

What Minecraft versions are supported?

Right now everything targets Minecraft 1.21.1 (Java Edition) on Fabric. If we add support for other versions, it'll be listed on the mod's Modrinth page.

Can I use your mods in a modpack?

Yes - modpack inclusion is allowed under our license (TSMLv1), with credit, whether you bundle the file or list it as a dependency from an official source. No need to ask first. See the full terms and the license that ships with each mod.

Can I re-upload or fork a mod?

You can publicly fork the source for personal tinkering or to contribute back. What you can't do without permission is re-upload the mod (source or a compiled build) to Modrinth, CurseForge, or anywhere else. If you want to do something the license doesn't cover, email us and ask - we read them. Details are in the Terms of Use.

I found a bug / I have a feature idea. Where does it go?

Open an issue on the mod's GitHub repo - for example Jenga Mod issues. Include your Minecraft and loader versions, the other mods you're running, and what you did vs. what happened. A crash log (pasted to mclo.gs) helps a lot.

Can I request a mod you saw in a YouTube video?

That's literally how Jenga Mod happened. Head to the contact page and send the link (or a description). No promises, but we read every request.

Is Toaster Studios affiliated with Mojang or Minecraft?

No. We're an independent fan project and are not affiliated with, endorsed by, or sponsored by Mojang Studios or Microsoft. Minecraft is their property; we just make mods for it.
